# Aula 04 — Estrutura e Arquitetura de Sistemas Operacionais

A aula explicou a estrutura interna dos sistemas operacionais e a importância deles para o funcionamento dos computadores. Sem um sistema operacional, cada programa precisaria controlar diretamente o hardware, a memória, o processador, os dispositivos e os arquivos. O SO facilita esse trabalho ao oferecer uma camada de comunicação entre os programas e os componentes físicos.

Foram apresentados os principais componentes de um sistema operacional: o kernel, responsável por gerenciar os recursos fundamentais; o gerenciamento de processos e memória; o sistema de arquivos; os mecanismos de entrada e saída; e os drivers, que permitem a comunicação com dispositivos de hardware. O kernel foi destacado como o núcleo do sistema, responsável por controlar processos, memória, dispositivos e segurança.

A aula também explicou a diferença entre modo usuário e modo privilegiado. Aplicações comuns funcionam com permissões limitadas e solicitam serviços ao kernel por meio de chamadas de sistema. Esse modelo ajuda a proteger o computador contra falhas e acessos indevidos.

Outro assunto importante foi a diferença entre programa, processo e thread. Programa é um arquivo armazenado, processo é um programa em execução e thread é um fluxo de execução dentro de um processo. Também foram estudados o sistema de arquivos, que organiza informações em diretórios, e os drivers, que controlam a comunicação com periféricos.

Por fim, foram propostas atividades para documentar o processo de instalação de um sistema operacional e pesquisar sistemas que utilizam como base outros sistemas já existentes, como exemplos de reaproveitamento de tecnologias.
