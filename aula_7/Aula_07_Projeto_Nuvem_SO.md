# Aula 07 — Projeto: Nuvem e Sistemas Operacionais

A aula deu continuidade ao projeto de computação em nuvem iniciado anteriormente. O objetivo foi ampliar uma aplicação desenvolvida com Node.js e Express, que inicialmente apresentava informações básicas do computador, transformando-a em um dashboard de monitoramento do sistema operacional.

Foi retomado o processo de criação de uma API REST com Express, incluindo a instalação das dependências necessárias e a preparação do projeto para execução com Node.js. Também foi revisada a publicação de aplicações na plataforma Render, utilizando um repositório do GitHub conectado ao serviço de hospedagem.

A proposta do dashboard é reunir informações importantes em uma interface organizada. Entre os indicadores previstos estão o uso da memória RAM, o consumo médio da CPU, o tempo de atividade da máquina, a quantidade de arquivos do projeto, o endereço IP principal e o status geral do sistema. O painel também deve apresentar dados técnicos, como hostname, tipo e versão do sistema operacional, versão do kernel, arquitetura, endianness e versão do Node.js.

Outro objetivo é identificar se a aplicação está sendo executada localmente ou em um ambiente de nuvem. Para isso, devem ser exibidas informações sobre variáveis de ambiente, porta utilizada e modo de execução. A atividade também propõe publicar a aplicação em outra plataforma semelhante ao Render e comparar os ambientes, registrando os resultados em um relatório.
