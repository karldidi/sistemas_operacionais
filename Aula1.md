# O que é um Sistema Operacional?

Um Sistema Operacional (SO) é o software responsável por gerenciar os recursos do computador, funcionando como uma interface entre o usuário, os programas e o hardware.

### Principais funções
- Gerenciar o hardware.
- Controlar a execução de programas.
- Administrar memória, processador e dispositivos.
- Fornecer uma interface para o usuário.

### Exemplos
- Windows
- Linux
- macOS
- Android
- iOS

---

# Estrutura Interna dos Sistemas Operacionais

Os sistemas operacionais possuem uma organização interna que permite seu funcionamento de forma eficiente.

## Kernel
O Kernel é o núcleo do sistema operacional e possui acesso direto ao hardware.

Suas principais responsabilidades são:
- Gerenciamento de processos;
- Gerenciamento de memória;
- Controle dos dispositivos de entrada e saída;
- Administração dos recursos do sistema.

## Modos de Operação

### Modo Usuário
- Executa programas comuns.
- Possui acesso restrito aos recursos do sistema.

### Modo Kernel
- Possui privilégios elevados.
- Pode acessar diretamente o hardware.

---

# Escalonamento de Processos

O escalonamento define qual processo utilizará o processador e por quanto tempo.

## Objetivos
- Melhor desempenho;
- Justiça entre processos;
- Redução do tempo de resposta.

## Algoritmos apresentados
- FIFO (First In, First Out)
- Round Robin
- Prioridade

---

# Gerenciamento de Memória

O sistema operacional é responsável por administrar a memória utilizada pelos programas.

## Memória Principal
- Alocação dinâmica;
- Proteção da memória.

## Memória Virtual
Permite utilizar parte do armazenamento como extensão da memória RAM.

Principais técnicas:
- Paginação;
- Segmentação.

Benefícios:
- Maior flexibilidade;
- Melhor aproveitamento da memória;
- Mais segurança.

---

# Gerenciamento de Dispositivos e Arquivos

## Entrada e Saída (E/S)

Responsável pelo controle dos dispositivos periféricos, como:
- Teclado;
- Mouse;
- Impressoras;
- Discos.

## Sistema de Arquivos

Organiza o armazenamento das informações e permite acessar os dados de maneira eficiente.

---

# Segurança e Virtualização

## Segurança

O sistema operacional deve proteger os dados e impedir acessos não autorizados.

## Virtualização

Permite executar diferentes ambientes computacionais utilizando o mesmo hardware, proporcionando melhor utilização dos recursos.
